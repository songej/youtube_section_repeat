# Release notes

## 1.9.30 {#v1-9-30}

- Starting a repeat no longer makes a playing video pause for a moment.
- The “Please reload the page” message no longer appears while YouTube is still rebuilding its player controls.
- When YouTube shows an error instead of a video, for example for a private or deleted video, the extension’s popup now says so instead of listing shortcuts.
- Clearer, more consistent wording in Chinese, Hindi, Indonesian, Japanese, Korean, Russian, Spanish and Turkish.

Permissions and saved sections are unchanged.

## 1.9.29 {#v1-9-29}

Testing and release checks only. Nothing changed in how the extension works.
